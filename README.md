# 🔄 SkillSwap - 技能互换平台 (Interactive Product Prototype)

> 告别昂贵学费，用你的特长交换你的渴望。一个基于 AI 设计理念构建的零成本技能互换平台原型。

---

## 🌟 项目简介

在现代社会中，许多人渴望学习新技能（如编程、外语、乐器），但常面临**“报班贵、自学难坚持”**的痛点；与此同时，个人拥有的特长却缺乏变现和分享渠道。

**SkillSwap** 旨在打破知识壁垒，通过“点对点”的技能互换机制，让时间与才能双向流动。本项目是一个高保真的前端交互原型，完整跑通了从**发现需求、智能匹配、发布技能到 1V1 沟通**的核心业务闭环。

## 🚀 核心功能模块

1. **精选技能广场（多维筛选与智能匹配）**
   - 支持多分类实时过滤（编程技术、语言学习、音乐艺术、生活运动）。
   - 引入 **Match Score（智能匹配度）** 算法概念，直观呈现用户间的契合度。
   - 包含实名认证标识与信用分体系，降低陌生人社交的信任门槛。

2. **技能发布闭环（UGC 内容生产）**
   - 用户可随时点击顶部“发布技能”按钮，填写“我擅长的（教）”与“我想学的（学）”。
   - 提交后实时渲染至广场卡片流，模拟真实社区的动态更新。

3. **1V1 沉浸式站内信与契约互换**
   - 点击“发起交换”即可拉起拟真的聊天对话框。
   - 独特的**“结构化互换契约”**功能，支持一键发送交换提议（如预估时长与授课方式），告别无效闲聊。

4. **个人中心与平台运维体系**
   - 侧边栏个人主页：集中管理个人信用分、实名认证及历史发布记录。
   - 平台客服与管理员通道：为用户提供纠纷申诉、账号安全和功能反馈的闭环入口。

## 🛠️ 技术栈

- **前端架构**：HTML5, JavaScript (ES6+), Single Page Application (SPA) 原生驱动
- **UI 框架**：Tailwind CSS (通过 CDN 引入，实现现代化响应式设计)
- **图标库**：FontAwesome 6.4
- **部署托管**：GitHub Pages (支持持续集成与热更新)

---

## 💡 产品设计思考 (Product Insights)

- **信任机制**：技能互换的核心痛点在于“安全感”。平台通过引入**实名认证徽章**与**信用评分**，最大程度减少用户的顾虑。
- **转化效率**：将模糊的“交友聊天”转化为结构化的**“互换契约”**，明确双方的权责，提升达成率。
